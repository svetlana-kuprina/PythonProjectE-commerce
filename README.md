## Система платежей для интернет-магазина.

Которая включает в себя набор классов и модулей:

* Класс Product - Обрабатывает информацию по продукте

* Класс Category - Обрабатывает информацию о категориях товара
### Использование

Для запуска используйте main.py.


### Тестирование

Проект покрыт юнит-тестами которые находятся в папке tests. Для их запуска выполните команду:
```
pytest --cov=src --cov-report=html
```
* Проект находится в разработке.
